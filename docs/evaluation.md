核对日期：2026-10-13。以下是私有项目报告的公开摘要，本次整理没有重新运行完整业务评测。各记录保留测量日期和范围，不将历史指标替换为当前版本的结果。

## 1. 历史已知来源召回 · 2026-08-10

500 条历史查询按领域分层，并冻结为 300 calibration / 100 validation / 100 holdout。标签包含 111 个独立来源与 2,256 个 query–source 关系，表示同一历史查询曾经观察到该来源。

| 阶段 | Hit@50 | Macro known-source recall | MRR |
| --- | ---: | ---: | ---: |
| FTS Top-50 | 36.4% | 11.72% | 6.07% |
| Vector Top-50 | 83.0% | 45.28% | 31.37% |
| 等权 RRF Top-50 | **83.8%** | **47.56%** | 22.56% |

RRF 的 macro recall 相对 vector-only 增加 **2.28 个百分点**，query-level paired bootstrap 95% CI 为 `[0.98, 3.76]`。MRR 同时下降 **8.81 个百分点**，说明候选覆盖扩大，但重排前顺序变弱。

这套标签没有全库负例，不能得出全语料 precision 或相关性准确率。500 条查询也不是 500 个独立来源；来源级敏感性分析的增益区间包含零，不能把 query-level 区间直接外推为所有来源上的稳定提升。

FTS / vector 权重 `0.1 / 1.0` 是 calibration 选出的离线候选，在 100-query holdout 的 Hit@50 为 82.0%、macro recall 为 47.25%、MRR 为 34.09%。它没有因此直接替换当时的生产配置。

## 2. 人工候选池质量评测 · 2026-08-08

36 条锁定查询覆盖用户声音、政策、竞品、付费代理、合规和数据源六类证据。1,412 个真实候选、901 个原始来源组均有逐候选 relevance / admission 双标签，两个标签分别回答“相关吗”和“能支持此类结论吗”。

| 指标 | 结果 |
| --- | ---: |
| RRF Top-50 macro 来源组覆盖 | 100.00% |
| BGE Reranker Top-10 macro 来源组覆盖 | **94.33%** |
| Evidence-fit admissible 来源组覆盖 | 87.98% |
| Evidence-fit micro 条件精确率 | **100.00%** |
| 错误领域误放 / 权威性不匹配误放 | 0 / 0 |

来源组覆盖按 `命中的不同金标来源组 / min(K, 金标来源组总数)` 归一化，避免同一文章的多个片段重复计分。它与逐候选 Recall@K 不等价：逐候选 recall 分别为 RRF 86.01%、Reranker 69.80%、evidence-fit 74.94%。

**100% 是这个审核池中的条件精确率，不能写成系统准确率或零幻觉保证。** 该候选池也没有对数据库全量语料进行穷举标注。

CPU 环境的检索全链路 P95 为 **58.988 秒**，主要耗时来自重排。这项记录通过质量及离线 / 批处理验证，未通过交互式延迟验收；目标 GPU 环境必须另测。

## 3. 真实运行与优化 · 2026 年 8 月

历史成功候选链约 **28 分 30 秒**、22 次模型调用，完成研究、当时的五位专家两轮讨论和一份机会产物。包含前置超时重试的完整任务约 **67 分 15 秒**，两者是不同时间窗口。

这是一条历史路径的完成记录，不是平均时延、稳定 SLA，也不表示当前主流程仍有五位专家。

对同模型、同候选、同来源的八个固定专家调用做上下文投影对照，prompt tokens 从 **157,041 降到 141,772，减少 9.7%**。两组均保留当时的专家、维度及响应合同。该结果仅适用于被调整的调用集，不代表全任务成本下降 9.7%。

## 4. 风格专家真实验收 · 2026-10-13

专用 Qwen3.8-Max 执行一条新任务，完成 **33 个来源、52 个观察块、9 次有界补检、105 次模型调用**，并登记私有草稿。

评测对八个场景分别运行通用基线和加载风格资产后的对话，每种条件三轮，共 **48 条实际回答**；再由单独的模型评测调用检查表达、互动、多轮一致性、事实和身份边界。105 次是整个蒸馏任务的模型调用数，包含语料处理与评测，不是对话次数。

最终 **8/8 用例通过**，题设约束、越界拒答及语料事实隔离在该轮检查中通过。新建资产仍为待人工审核草稿，未自动用于正式路由。

这项结果证明指定材料和指定用例下的一次完整任务能够登记草稿，不能证明：

- 蒸馏总体成功率、跨人物泛化能力或长期稳定性；
- 已复现真实人物的完整人格、私人观点或情绪体验；
- 自动评分等同人工质量判断；
- 已完成真实知识库内容充分性验收或生产部署。

## 如何复核这些结论

公开仓库提供统计口径、日期、设计边界和摘要，不发布私有报告、原始语料、候选标签、模型轨迹或数据库。面试交流可按“问题 → 测试设计 → 原始记录 → 修正 → 再验收”的顺序说明实现。
