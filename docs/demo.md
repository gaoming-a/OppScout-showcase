# 界面演示与研究导览

[项目首页](../README.md) · [文档索引](README.md) · [系统架构](architecture.md)

本页展示已有真实界面的静态截图，来自 2026 年 8 月。截图用于理解交互与产物，不提供在线试用账号；当前开发版本的工具入口、固定四角色主流程与风格专家见[架构说明](architecture.md)。

## 1. 输入研究问题与项目背景

用户给出研究方向与背景，系统建立研究任务。左侧保存历史，主区域呈现输入与后续研究文档。

![研究工作台入口，历史版本](../assets/oppscout-home.png)

可以关注：模糊研究方向如何变成明确的任务，用户如何回到历史结果。

## 2. 查看研究、引用与未解决的缺口

研究文档保留来源入口、证据与结论的关系；用户可以沿文档查看过程并继续追问。截图中的“领域专家”属于当时的流程，当前主流程已经改为项目校准与固定角色评审。

![研究正文、来源入口与过程导航，历史版本](../assets/oppscout-research-document.png)

可以关注：哪些信息来自来源，哪些是研究判断，缺少的证据如何体现。

## 3. 从结论到决策产物

产物展示建议动作、证据、风险和置信度。相同研究入口可以形成产品机会、继续验证或不建议推进，证据不足的方向会保留验证任务。

![决策产物与证据详情，历史版本](../assets/oppscout-decision-artifact.png)

可以关注：用户能否理解结论为何成立，是否仍需要进一步验证。

## 当前开发版本的演示顺序

面试中的实现交流可以按以下顺序进行，具体是否能运行外部调用取决于当次环境：

1. 从统一对话发起类型化机会研究，查看输入绑定与独立任务进度。
2. 展开研究来源、引用及最终产物，解释证据如何进入结论。
3. 发起独立舆情研究，说明时效、样本范围与机会评分的差别。
4. 查看一份风格专家草稿及三轮对照评测，解释风格和知识的授权边界。
5. 对照一次暂停、重启或未知调用记录，说明何时复用已确认结果、何时必须停止。

当前版本尚未完成全部公网发布验收，以上顺序是实现交流导览，不代表提供可用的公共在线服务。
