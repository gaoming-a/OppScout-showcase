# 精炼架构：三类能力，一个研究工作台

[项目首页](../README.md) · [真实运行 SOP](demo.md) · [功能成果](results.md)

![OppScout 系统架构示意图](../assets/oppscout-architecture.png)

用户提出问题，系统规划并推进任务，连接三类研究能力：

- **机会研究**：发现需求、深度分析，输出研究报告、用户线索与验证建议。
- **舆情研究**：归纳公开观点、保留来源，输出舆情报告。
- **专家定制**：提炼资料与表达风格，形成可复用专家资产。

多源情报与知识支持贯穿其中；工作台负责呈现进度、研究内容和最终成果。
